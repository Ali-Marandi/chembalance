# ChemBalance Desktop — Product Specification

## Purpose

ChemBalance Desktop is a local-first Windows application for students, educators, laboratory staff, and scientists who need fast, transparent, and mathematically exact balancing of chemical equations. The application must preserve the repository’s core principle: integer coefficients are derived using rational linear algebra rather than floating-point approximation.

## Product Positioning

The first desktop release is designed as a dependable calculation and teaching tool, not as a chemical-reaction predictor. It balances valid user-supplied reactions, verifies conservation of each element and net charge where relevant, and clearly discloses that mathematical balance does not by itself establish chemical plausibility.

The feature baseline combines the immediate balancing and history patterns common in comparable consumer tools with the detail, editable equation display, and validation expected from professional desktop software. [Advanced Chemical Equation Balancer](https://lab.learnbin.net/tools/advanced-chemical-equation-balancer/) identifies nested groups, hydrates, ionic charges, exact fraction arithmetic, and a stoichiometry table as high-value capabilities. [ChemBalance for Apple platforms](https://apps.apple.com/us/app/chembalance/id6738868211) provides a useful benchmark for step explanations, history, examples, and export.

## Version 1.0 Scope

| Area | Delivered capability |
| --- | --- |
| Equation entry | A single natural equation field accepts `+`, `→`, `->`, `=`, or `⇌` separators, with live syntax feedback and keyboard-first operation. |
| Formula support | Element symbols, integer subscripts, nested parentheses and square brackets, hydrates using `·` or `.`, leading molecule multipliers, and bracketed ionic charges such as `[Fe^2+]` and `[MnO4^-]`. |
| Exact engine | Fraction-based Gaussian elimination finds the smallest positive integer coefficients and detects invalid, underdetermined, or non-positive balances. |
| Results | A professionally typeset balanced equation, an atom/charge verification table, coefficient cards, compound molar masses, and a short solution narrative. |
| Learning and productivity | Curated examples, one-click copy, plain-text export, local searchable history, clear-history control, and light/dark themes. |
| Safety and trust | Local-only history, no telemetry, an in-app scope disclaimer, accessible labels, focused keyboard navigation, and detailed actionable error messages. |
| Distribution | A Windows executable generated by a reproducible GitHub build workflow, a documented build specification, and release assets published through GitHub Releases. |

## Experience Design

The application uses a restrained scientific visual system: deep indigo navigation, high-contrast neutral surfaces, a teal accent for successful balance verification, and amber/red only for warnings or errors. The primary workspace is centered around a single equation input and a prominent **Balance Equation** action. Results appear without forcing the user to change context: the balanced equation is at the top, followed by a compact verification matrix and a stoichiometry panel. A sidebar offers Examples, History, and About.

The interface must remain usable at 1280 × 720 and scale cleanly on high-DPI Windows displays. It supports standard clipboard shortcuts, `Ctrl+Enter` to balance, `Ctrl+C` to copy the balanced equation, and tooltips for advanced syntax.

## Explicit Non-Goals for 1.0

The application does not infer products, validate reaction conditions, predict equilibrium, replace chemical safety review, or handle nuclear reactions. Redox half-reaction balancing in explicitly acidic/basic media is outside the initial release; however, the general charge-aware equation engine accepts and verifies charged species supplied by the user.

## Quality Gates

A release candidate must pass unit tests covering parsing, nested groups, hydrates, ionic charges, exact integer normalization, malformed input, and conservation verification. The GitHub Actions pipeline must test supported Python releases, build the Windows executable on a Windows runner, and attach the executable and SHA-256 checksum to a GitHub Release.

## Acceptance Examples

| Input | Expected balanced result |
| --- | --- |
| `H2 + O2 -> H2O` | `2H₂ + O₂ → 2H₂O` |
| `Fe + O2 -> Fe2O3` | `4Fe + 3O₂ → 2Fe₂O₃` |
| `Ca(OH)2 + H3PO4 -> Ca3(PO4)2 + H2O` | `3Ca(OH)₂ + 2H₃PO₄ → Ca₃(PO₄)₂ + 6H₂O` |
| `CuSO4·5H2O -> CuSO4 + H2O` | `CuSO₄·5H₂O → CuSO₄ + 5H₂O` |
| `[Fe^2+] + [MnO4^-] + [H^+] -> [Fe^3+] + [Mn^2+] + H2O` | `5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O` |
